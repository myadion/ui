Adion UI Kit

Documentation v1.2

About

Created and designed by Adion, Adion UI Kit Design is a design language that combines the classic principles of successful design along with innovation and technology. Adion's goal is to develop a system of design that allows for a unified user experience across all their products on any platform.

Download

Adion UI Kit comes in two different forms. You can select which version you want depending on your preference and expertise. To start using Adion UI Kit, all you have to do is download one of the options below.

Adion UI Kit

This is the standard version that comes with both the minified and unminified CSS and JavaScript files. This option requires little to no setup. Use this if you are unfamiliar with Sass.


Adion UI Kit

Sass

This version contains the source SCSS files. By choosing this version you have more control over which components to include. You will need a Sass compiler if you choose this option.
